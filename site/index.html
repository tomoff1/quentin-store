PREMIÈRE INSTALLATION

Un ELF. Un chargeur. Votre console.

Prérequis

PS5 déjà jailbreakée, ELF Loader compatible actif sur le port 9021. QUENTIN STORE n’effectue pas le jailbreak.

Le firmware 13.60 est une cible à tester. ShadowMountPlus n’est pas utilisé pour installer ce payload. Aucun PKG n’est fourni.

  1. Telechargez uniquement quentin-store.elf.
  2. Envoyez cet ELF a votre chargeur compatible deja actif.
  3. Le store cree ses donnees automatiquement : aucun fichier annexe a copier par FTP.
  4. Utilisez L1/R1 pour les onglets, X pour ouvrir et Triangle pour actualiser.
