# Local LibProsperoPKG modification

Upstream: SvenGDK/LibProsperoPKG commit 748eabf1b7d17819528cabf367d8e27109d8fce3, GPL-3.0-or-later.

The call to EnsureAboutRightSprx is disabled. The embedded right.sprx resource declaration and binary are removed. Its provenance could not be verified. The ordinary package layout, metadata, encryption, and validation remain generated by the public library. This omission may affect console acceptance and is explicitly not a proven compatibility fix.

Reproduce the modification by running patch_no_right.py against the same unpacked source. The CLI Program.cs verifies all source files survive packing and extraction byte for byte, checks native module classification and PS5 finalized-package structure, and rejects an injected right.sprx. Console execution remains untested.
