QUENTIN STORE 0.1.0 — première version expérimentale.

Deux ELF natifs compilés avec le SDK public ps5-payload-sdk v0.44 et LLVM 18.1.8 : le store et Quentin Blocks, jeu original GPL-3.0-or-later.

Catalogue JSON, interface SDL et manette, recherche, catégories, fiches, HTTPS avec validation TLS, reprise HTTP Range, SHA-256, historique et mises à jour manuelles.

Les tests locaux et la compilation ne constituent pas une validation sur PS5. L'exécution sur firmware 13.60 reste à tester. Aucun PKG, aucune installation automatique et aucun titre ShadowMountPlus dans cette version.

Suivre docs/INSTALLATION-PS5.md et vérifier SHA256SUMS avant transfert.
